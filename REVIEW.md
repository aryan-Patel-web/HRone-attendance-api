## Looked at and decided it was fine

* `load_dotenv()` (L20): the default is `override=False`, so real environment variables already win over `.env` as required.
* `IST = timezone(timedelta(hours=5, minutes=30))` (L25) is correct (IST has no daylight saving). I kept it.
* Endpoints are plain `def` with the synchronous PyMongo driver: FastAPI runs them in a thread pool, so they do not block the event loop. Switching to Motor would add complexity without benefit here.
* `db.employees.find(q, {"_id": 0})` already hides `_id` in the employee list; the issue there was only the missing sort / wrong skip / wrong total.
* Default shifts `09:30`-`18:30` match the contract defaults.
* `doc.pop("_id", None)` after `insert_one` in `create_employee` is harmless (insert adds `_id` to the dict). I replaced it with the serializer only for consistency.
